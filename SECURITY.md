# Security Policy

## What this site does
- Read-only: the balance checker only looks up a **public** XRP address on the **XRPL Testnet or Mainnet** (read-only).
- It never asks for, accepts or stores a seed, secret key or private key, and never signs or submits transactions.
- Everything runs in your browser. There is no server and no sign-up. The XRPL library (xrpl.js 4.7.0) is self-hosted in `assets/vendor/`.

## Reporting a vulnerability
Please report issues **privately**, not in a public issue:
1. Go to this repository's **Security** tab.
2. Click **Report a vulnerability** to open a private GitHub security advisory.
3. Describe the issue and how to reproduce it.

You'll get a reply as soon as possible. Thanks for helping keep users safe.

## Staying safe
Never share your seed or secret key with anyone. Ripple and Xaman will never DM you. Always check the URL before connecting a wallet.
