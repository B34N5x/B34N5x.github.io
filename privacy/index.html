Privacy

Plain English, short version. Updated 2026-10-29.

  • No accounts. There is no sign-up, login or wallet connect, ever.
  • No secrets. We never ask for seeds, secret keys, passwords or signatures, and never submit transactions.
  • Runs in your browser. The tools are read-only. Addresses or transaction IDs you type go straight from your browser to public XRP Ledger servers (e.g. xrplcluster.com, s1.ripple.com, XRPL Testnet) to look up public data. We don't store them.
  • One small local note. When you tick the Terms box on a checker, your browser saves only the terms version and the time you accepted (localStorage). It never leaves your device and you can clear it any time.
  • No tracking. No analytics, ads, cookies, session recording or third-party fonts. Some pages show an anonymous visit count: it sends only the page path, sets no cookies, and stores no IPs or personal data.
  • Hosting. The site is hosted on GitHub Pages, which may keep standard server logs (such as IP addresses) as described in the GitHub Privacy Statement.
  • The Lobby. When open, The Lobby is a game for ages 13+. Please don't share personal info in rooms or chat. To report a problem, open an issue on GitHub.

This is general info, not legal advice.
