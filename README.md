# B34N5x.github.io

Personal site for B34N5x: small, open-source tools for the XRP Ledger, built while learning in public.

- Plain HTML, CSS and vanilla JavaScript. No build step, no server, no sign-up.
- The balance checker runs in your browser on the XRPL **Testnet** and **Mainnet** (read-only) and only ever needs a public address. It never asks for a seed or secret.
- Adding a tool: create `tools/<tool-name>/index.html` and add one card to `tools/index.html`.

Run locally: `python -m http.server` then open http://localhost:8000.
