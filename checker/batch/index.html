1 Paste your list

Network
More info

Only public addresses (start with “r”) or 64-character transaction hashes. Never paste a seed or secret key.

Rate limit: checks run one at a time with a short pause (~0.2s) so public nodes are not flooded. Max 50 lines per run.

If a node times out, the tool retries the next public node and marks the line if none answer.

Handy at tax time? Export a CSV for your own records. This is a read-only lookup helper only — not financial or tax advice, and it does not prepare a tax return.

2 Results

What do these numbers mean?

Balance — total XRP on that address.

Reserve — XRP locked by the network so the account can exist (plus a bit per item it holds).

Spendable — roughly balance minus reserve; what can usually be sent.

Figures come from public XRPL nodes and may be briefly delayed or wrong.
