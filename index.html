Why these tools

The XRP Ledger is open source, and its tools should be too. Many people want to use features like escrow but find existing tools complex or unclear. Each tool here does one job, explains it in plain words, and uses only the ledger's own built-in features. Every line of code is public on GitHub.

Security first

No accounts, no sign-ups, no cookies. No personal data is stored; the only record is an anonymous visit count. Your wallet signs every transaction itself, and these tools never hold your funds or keys.

What are XRP and the XRPL?

The XRP Ledger (XRPL) is a public, open-source blockchain that has been running since 2012 and settles payments in a few seconds for a tiny fee. XRP is its built-in currency, used to pay those fees and to move value. Anyone can use it with their own wallet, where you hold your own keys. XRPL Will runs only on Testnet, which uses free test XRP with no real value. Learn more at xrpl.org.

Free, open-source tools that make common XRPL tasks easy. They run in your browser, never ask for seeds or keys, and never store anything about you.
